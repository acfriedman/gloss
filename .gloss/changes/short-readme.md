# A README you can read in a minute

The README had grown into the app's manual, one paragraph per feature, until it ran past 400 lines and
buried how to install and run gloss. It now keeps to what a newcomer needs, in the style of Lyceum's:
what gloss does, what it needs, how to start, its commands, the app at a glance, change stories, the rules,
exemptions, the environment variables, the package's targets, and the license. The details it dropped live
in the docs gloss already requires, where the app shows them.
