# GlossPage

Renders the arranged interface as one self-contained HTML page, for CI and for sharing. It shows only what the model holds, so a gap on the page is a gap in the model.

## Overview

``InterfacePage`` draws from the same ``Atlas`` as the app, so the two never disagree. The page loads nothing and stamps no time, so the same sources always render the same bytes. It is shrinking toward a pull request's report of findings and changes.
