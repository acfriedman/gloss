# gloss

The command line: it exports the interface, checks a branch's story, and times the app's work. The lint is SwiftLucid's own command, `swiftlucid`.

## Overview

``Export`` writes the interface as JSON, ``StoryCheck`` runs `gloss story`, and ``Bench`` times each phase of the app's work.
